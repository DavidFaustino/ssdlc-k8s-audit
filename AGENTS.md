# Orientações do projeto

Este projeto reúne explicações e um kit de leitura para preparação de auditoria AWS/Kubernetes.

- Manter linguagem didática: significado, fluxo, exemplo e evidência. Usar diagramas quando facilitarem a compreensão.
- Diferenciar cenário informado, desenho recuperado, configuração observada e eficácia demonstrada.
- Preservar os 21 itens e a rastreabilidade de evidências; não declarar conformidade automaticamente.
- O toolkit existente foi preservado; alterações futuras exigem testes proporcionais e atualização do runbook.
- Não incluir segredos, resultados corporativos ou identificadores de organizações no conteúdo público.
- Não executar consultas a contas ou mudanças reais só porque a documentação mostra comandos.
- Não confundir CSI/distribuição com rotação na origem ou adoção pela aplicação.
- Mudanças de diagramas devem atualizar o SVG e a fonte DOT correspondente.
- Publicação não implica aprovação interna do guia.

Estruturação inicial realizada com a skill writing-plans. Diretório preparado para o repositório ssdlc-k8s-audit.
